This repository contains modifications and experiments.

---

## 🦇 About

Martin's Dungeon Bash is a simple roguelike game.

---

## 🧌 Goal

The main goal of this project is to provide for Martin's Dungeon Bash:

- A maintained GitHub repository
- CI/CD workflows
- Automated tests
- A more advanced Makefile

Fixing, improving or adding more features are not goals of this project, but might be part of it in the future
